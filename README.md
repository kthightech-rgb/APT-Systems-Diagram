# 공동주택 설비계통 이해하기

공동주택 관리소장·직원을 위한 **설비계통 3D 교육자료**입니다. 설치 없이 브라우저에서 바로 봅니다.

- 바로 보기: https://kthightech-rgb.github.io/APT-Systems-Diagram/
- 8편: 수전설비 · 급수설비 · 소방설비 · 난방·급탕설비 · 오수·배수·우수 · 승강기 · 홈네트워크·통신·CCTV · 주차장 환기·EV 충전
- 각 단계는 주소 끝 `#s번호`로 바로 열 수 있습니다.

## 이용 안내

- 이 앱은 래온(來On)이 만든 무료 도구이며, 국토교통부·K-apt·중앙공동주택관리지원센터·주택관리사협회의 공식 서비스가 아닙니다.
- 결과물은 작성 보조용 참고자료입니다. 법령 적용과 최종 내용의 확인·책임은 사용하는 관리주체에게 있습니다.
- 입력한 내용·파일·인증키는 이 브라우저에만 저장되며 제작자에게 전송되지 않습니다. 화면 구성용 라이브러리를 외부(cdnjs·jsDelivr·Google Fonts)에서 불러오므로 접속 기록은 GitHub와 해당 CDN에 남을 수 있습니다.
